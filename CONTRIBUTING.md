Obrigado por contribuir!

Como contribuir:
1. Abra uma issue para discutir grandes mudanças.
2. Crie uma branch com nome descritivo.
3. Siga os templates em notes/ e exercises/.
4. Faça um pull request; descreva o que foi adicionado e testes, se houver.

Normas rápidas:
- Escreva em Português (ou inglês quando necessário).
- Inclua referências quando usar material externo.
