# Avaliação — AEDS 3

A disciplina possui 4 provas (P1, P2, P3, P4), cada uma valendo 24 pontos, para um total de 96 pontos.

Formato
- Provas teóricas e práticas (dependendo do professor): questões dissertativas, algoritmos, e problemas de implementação.
- Podem haver trabalhos ou projeto complementares (ver docs/syllabus.md).

Distribuição de tópicos (sugestão)
- P1 (24 pts): Parte 1 — Arquivos, índices (hash, B+), estruturas de dados básicas.
- P2 (24 pts): Parte 2 — Compressão, criptografia, casamento de padrões, algoritmos de string.
- P3 (24 pts): Parte 3 — (preencher com conteúdos do curso: e.g., grafos, estruturas avançadas, otimizações).
- P4 (24 pts): Parte 4 — Prova cumulativa / projeto final / resolução de problemas complexos.

Critérios de aprovação
- Total possível: 96 pontos.
- Defina a política de aprovação (ex.: >= 60% do total) com o professor.

Recomendações
- Use os templates notes/exam*-template.md para organizar revisões por prova.
- Registre notas em docs/gradebook.md para acompanhar desempenho.
