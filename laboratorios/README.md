# Laboratórios — AEDS III

## Sobre os Trabalhos Práticos (TP)

Os trabalhos práticos são atividades de implementação obrigatórias que cobrem os tópicos principais do curso. Cada TP tem enunciado detalhado em arquivo separado nesta pasta.

### Cronograma

| TP | Tópico | Semana | Peso | Arquivo |
|----|--------|--------|------|---------|
| TP1 | Manipulação de Arquivos | 5 | 5% | TP1-Manipulacao-Arquivos.md |
| TP2 | Compressão (Huffman) | 8 | 5% | TP2-Compressor-Huffman.md |
| TP3 | Criptografia (AES/RSA) | 13 | 5% | TP3-Criptografia.md |
| TP4 | Busca de Padrões (KMP/BM) | 15 | - | TP4-Busca-Padroes.md |

**Nota**: TP4 não tem peso na nota final, mas é obrigatória para completar compreensão do conteúdo.

## Instruções Gerais

### Submissão
1. Cada TP deve ser entregue em seu próprio diretório: `TP1/`, `TP2/`, `TP3/`, `TP4/`
2. Incluir arquivo `README.md` descrevendo:
   - Linguagem utilizada
   - Instruções de compilação/execução
   - Dependências (se houver)
   - Exemplos de uso

3. Fazer commit e push para repositório Git até a data limite

### Avaliação
- **Corretude**: Programa funciona conforme especificado
- **Desempenho**: Otimizações implementadas, se aplicável
- **Código**: Claro, comentado, sem código duplicado
- **Documentação**: README completo com exemplos

### Linguagens Suportadas
- C (gcc)
- C++ (g++/clang++)
- Java (JDK 8+)
- Python 3.6+

Outras linguagens sob consulta.

### Prazos
- **TP1**: Entrega até fim semana 5
- **TP2**: Entrega até fim semana 8
- **TP3**: Entrega até fim semana 13
- **TP4**: Entrega até fim semana 15

### Política de Atrasos
- Até 2 dias de atraso: -10% da nota
- Mais de 2 dias: -20% da nota
- Mais de 7 dias: 0 (não aceito, mas recomendado entregar mesmo assim para aprendizado)
