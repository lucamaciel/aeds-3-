# Anotações de Aulas — AEDS III

Esta pasta contém um arquivo para **cada aula** do semestre.

## Estrutura

```
anotacoes/
├── Semana01-Segunda-10-08.md
├── Semana01-Quarta-12-08.md
├── Semana02-Segunda-17-08.md
├── Semana02-Quarta-19-08.md
├── ... (até Semana 16)
└── Semana16-Quarta-25-11.md
```

**Total**: 32 aulas (2 por semana, segunda e quarta)

## Como Usar

1. **Antes da aula**: Abra o arquivo da aula correspondente
2. **Durante a aula**: Adicione notas em "Tópicos Abordados", "Conceitos-Chave", etc.
3. **Após a aula**: Complete com exemplos, dúvidas não resolvidas
4. **Antes de provas/testes**: Releia seus arquivos da semana anterior

## Formato de Cada Arquivo

Cada arquivo contém:
- **Data e Horário** da aula
- **Semana** e **Módulo** (MD01, MD02, MD03, MD04)
- **Tópicos Abordados** — o que foi discutido
- **Conceitos-Chave** — ideias principais
- **Exemplos e Exercícios** — implementações vistas
- **Dúvidas** — perguntas que ficaram
- **Próximas Aulas** — link para próxima aula

## Aulas Especiais

Algumas aulas têm formatos especiais:

### Testes Presenciais (5, 8, 13, 15)
- Campo "Resultado do Teste" para nota
- Revisão dos conceitos principais

### Provas (10, 16)
- Campos para questões respondidas
- Estimativa de pontuação
- Feedback pós-prova (quando disponível)

### Revisões (9, 16)
- Espaço para exercícios resolvidos
- Dúvidas tiradas

## Dica de Estudo

1. Leia as anotações de semanas anteriores antes da revisão
2. Organize por tópico (MD01, MD02, MD03, MD04)
3. Reuse este arquivo como "folha de cola" para estudar
4. Mantenha atualizado com git: `git add anotacoes/ && git commit -m "..."`
