Plano de Ensino — AEDS III (Algoritmos e Estruturas de Dados III)

Ementa Resumida
Manipulação eficiente de dados em arquivos; técnicas de compressão de dados; fundamentos de criptografia; algoritmos de busca de padrões em textos. Aplicação prática de estruturas avançadas e otimização de algoritmos para problemas de grande escala.

Objetivos Principais
- Implementar técnicas de I/O eficiente e manipulação de arquivos
- Aplicar algoritmos de compressão sem perda (Huffman, LZ77, RLE)
- Compreender criptografia simétrica e assimétrica
- Implementar e analisar algoritmos de busca de padrões (Boyer-Moore, KMP, Rabin-Karp)
- Otimizar soluções para problemas complexos
- Medir e melhorar desempenho de algoritmos

Carga Horária
Total: 90 h/a (40 prática, 50 teórica)
Módulos: MD01–MD04 conforme cronograma

Módulos Principais
1. MD01 — Manipulação de Dados em Arquivos
2. MD02 — Compressão de Dados
3. MD03 — Criptografia e Segurança
4. MD04 — Casamento de Padrões
