# Exercício — Parte 2: Compressão, Criptografia e Casamento de Padrões

Objetivo
- Implementar algoritmos básicos: Huffman (compressão) e KMP (casamento de padrões); aplicar criptografia simples em arquivos comprimidos.

Descrição
1. Implementar Huffman coding para comprimir/descomprimir arquivos de texto.
2. Implementar KMP para busca de padrões em textos grandes e medir desempenho comparado à busca naive.
3. Cifrar o arquivo comprimido com AES-GCM (usar biblioteca) e demonstrar processo de cifrar/decifrar com chave.

Requisitos
- Fornecer utilitários de linha de comando: compress, decompress, search, encrypt, decrypt.
- Testes com arquivos de tamanhos variados (por exemplo, 100KB, 1MB, 10MB).
- Documentar taxas de compressão e tempos.

Entrega
- solutions/pt2/<seunome>/ com código e relatório
- scripts de teste para automatizar medições

Critérios
- Correção e robustez
- Medições e comparações
- Uso adequado de bibliotecas para criptografia
